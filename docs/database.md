# 数据库与迁移

Flyway 是唯一正式数据库结构来源。生产 profile 只加载 `classpath:db/migration`；开发 profile 额外加载 `classpath:db/demo`，因此演示数据不会进入生产环境。

| 迁移 | 内容 | 环境 |
| --- | --- | --- |
| V1 | 用户、公司、岗位、简历、投递基础表 | 全部 |
| V2 | 基础演示账号和业务样例 | dev |
| V3 | 投递状态机、历史和幂等 | 全部 |
| V4 | 面试、提醒、通知和 SSE 相关表 | 全部 |
| V5 | Dashboard 聚合索引 | 全部 |
| V6 | 扩充演示数据 | dev |

V1—V5 已发布迁移不修改；开发数据使用固定主键 + `NOT EXISTS`，重复启动不会重复插入。生产数据库从空库启动时不会加载 V2/V6，也不会自动创建演示账号。

主要隔离约束：所有业务表保留 `user_id`，查询 SQL 同时带用户条件和逻辑删除条件；Dashboard 额外按归档、公司、来源和日期过滤。状态历史是漏斗、转化和周期指标的事实来源。
